How to read this

OKDEGRADEDDOWNUNKNOWN
  • functional — real read-only call succeeded — the module actually works
  • connect — endpoint/handshake reachable — auth or behaviour NOT proven
  • process — local service, port or process state
  • local — local file/import check, no network involved
  • config — configuration present; behaviour not exercised

Colour = state; the probe tag = the strength of the evidence. A module can only be called OK on evidence matching the claim: a server that handshakes but fails its real call is reported DOWN, not OK.
